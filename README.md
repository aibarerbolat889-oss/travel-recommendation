# Wanderly Travel Recommendations

This project is a responsive Travel Recommendation website built with HTML, CSS, and JavaScript.

## Features

- Home, About Us, and Contact Us sections
- Search input with Search and Clear buttons
- Recommendations for beaches, temples, and countries
- At least two image results for each search type
- Contact form with accessible labels

## Run locally

Open `index.html` in a browser, or use the Live Server extension in VS Code.
